# Roadmap

Deal Scout is intentionally small today. These are the next improvements that
would make it more useful without turning it into a heavy platform.

## Near Term

- Flipp-compatible flyer adapter.
- Price-history SQLite cache.
- Deduplication across sources by merchant/product.
- `--only-local` and `--only-online` filters.
- Better merchant-specific extraction recipes.

## Later

- Scheduled digest generation with GitHub Actions.
- Email/Telegram/Discord notifications.
- Lightweight web UI for browsing JSON output.
- Browser extension or bookmarklet for adding product pages.
- Community source gallery.
